# 儀器借用幫手

這是一個可直接部署的儀器借用表單。使用者可填寫借用醫院，並從 13 個
類別下拉選單複選多台儀器。系統會讀取 Google 試算表中的借用紀錄；
當天已借出的儀器仍可點選並加入備取。
備取選項會直接顯示目前借用該儀器的醫院名稱。

## 先在本機預覽

在此資料夾啟動靜態網站伺服器，再開啟顯示的網址即可。尚未串接 Google
試算表時，程式會使用示範資料，完整操作仍可測試。

## 串接 Google 試算表

1. 建立或開啟要使用的 Google 試算表。
2. 選擇「擴充功能 → Apps Script」。
3. 將 `google-apps-script/Code.gs` 的內容貼入編輯器並儲存。
4. 在 Apps Script 上方函式選單選擇 `setupSheets`，按「執行」並同意授權。
5. 選擇「部署 → 新增部署作業 → 網路應用程式」。
6. 執行身分選擇「我」，存取權選擇實際使用者可存取的範圍。
7. 複製部署完成的 `/exec` 網址。
8. 編輯 `config.js`：

```js
window.APP_CONFIG = {
  googleAppsScriptUrl: "貼上 /exec 網址",
  demoMode: false,
};
```

## 試算表結構

第一次執行 `setupSheets()` 後會自動建立：

- `儀器清單`：內建 13 類、共 67 個儀器編號，可自由修改分類、編號、畫面代碼及啟用狀態。
- `借用紀錄`：同一申請的每台儀器會各新增一列，並共用申請編號，僅供授權人員查閱與管理。

程式也會直接讀寫既有的 `MM月行程表`：

- A–E 欄：區域、儀器、編碼、設備資料、儀器位置。
- F 欄起每個日期占 6 欄：位置、時間、其他備註、區域、聯絡人、運送流程。
- 每台儀器占 4 列：原始位置加上 3 列目的地。
- 直接借用時，醫院寫入第一列目的地的「位置」，送達時間寫入原始位置的
  「時間」，取回時間寫入第一列目的地的「時間」。
- 備取時不覆蓋原借用資料，改在第一列目的地的「其他備註」追加
  `備取N:醫院名稱`。

例如 7 月 25 日 EX2 的日期區塊從 ET 欄開始，會寫入：

- `ET4`：借用醫院
- `EU3`：送達時間
- `EU4`：取回時間
- `EV4`：手術備註或備取資訊

送達與取回時間均以 30 分鐘為單位，使用 24 小時制；例如下午 2 點為
`14:00`。寫入月行程表時會呈現為 `送達08:30`、`取回14:00`。

送出表單後會先顯示日期、醫院、時間、儀器與備註，使用者再次確認才會寫入。
可直接借用的儀器會記為「已預約」，已借用的儀器則記為「備取中」。
APP 不提供取消功能，也不會因修改「借用紀錄」的狀態而自動取消或遞補。
需要解除借用時，由有試算表編輯權限的人員在 `MM月行程表` 手動清除該筆
醫院、送達時間、取回時間與相關備註；APP 下一次讀取時會同步恢復可借狀態。
後端在寫入前會逐台檢查借用狀態並加鎖，避免兩位使用者同時預約同一台儀器。
