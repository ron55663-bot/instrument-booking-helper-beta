# Changelog

## V1.4.0-beta.3

Status: Current Production Beta baseline

### Added

- Category calendar with aggregated availability and per-instrument details.
- Centralized calibration category for the three calibration devices.
- Delivery and pickup quick-time buttons with the existing 30-minute validation.

### Fixed

- Selected quick-time buttons now remain visible and use a clear selected state.
- Custom-time and initial-value states remain synchronized with the original time fields.

### Compatibility

- No Apps Script API changes.
- No Google Sheet schema changes.
- No booking record or monthly schedule format changes.
